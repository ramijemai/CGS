# Command & Ground Station (CGS)

CGS is a prototype command and ground station for managing drones from a bunker. It models drone storage, charging, mission dispatch, recovery, and telemetry through a C++17 backend with REST and WebSocket interfaces.

The project also includes a React and TypeScript frontend that provides an operator interface for monitoring the bunker and controlling missions. The current system is configured for one MAVSDK-connected drone and is intended as a foundation for a larger drone operations platform.
